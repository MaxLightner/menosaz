# منوساز

وب‌سایت فعال: https://maxlightner.github.io/menosaz/

فرانت React/Vite روی GitHub Pages است. تنها پایگاه عملیاتی Supabase پروژه zeeztpblibcqtxompvxa است؛ Firebase، SQLite و سرور ورود محلی حذف شده‌اند. سه نمای مشتری، گارسون و آشپزخانه و دو نمای موبایل/دسکتاپ مدیریت از یک API و مدل داده استفاده می‌کنند.

## اجرای محلی

Node.js 22.12 یا بالاتر و pnpm 10:

```text
pnpm install --frozen-lockfile
pnpm dev
```

نسخهٔ محلی نیز به همان Supabase وصل است؛ داده یا سفارش آزمایشی را بدون حساب/مجموعهٔ تست در آن ثبت نکنید. نمونه‌منوهای سایت پیش‌نمایش‌اند و با فرمان اتمی در حساب مدیر قابل کپی هستند. پیش‌نمایش نمونه سفارش واقعی ثبت نمی‌کند.

## ورود و نقش‌ها

OTPy در Edge Function کد می‌فرستد و تأیید می‌کند؛ نشست متعلق به Supabase Auth است. کلید پیامک و کلید مدیریتی فقط در Secrets سرور نگه‌داری می‌شوند. کلید عمومی مرورگر دسترسی مستقیم به جدول‌های خصوصی ندارد. ورود با «مرا به خاطر بسپار» در حافظهٔ محلی و در غیر این صورت در نشست تب حفظ می‌شود. QR مشتری ورود نمی‌خواهد.

مالک، دسترسی همکاران را در پنل تنظیم می‌کند. فقط گارسون دریافت وجه/ارسال/تحویل و فقط آشپزخانه تأیید آماده‌شدن را ثبت می‌کند. مشاهدهٔ پنل دیگر به حساب مدیر مجوز عملیات آن نقش را نمی‌دهد.

## مدل داده و انتشار

کسب‌وکار، منو، دسته، محصول، رسانه، نقطه، QR، نشست، سفارش و رویدادها جدول مستقل دارند. اشتراک و پرداخت پلتفرم از دریافت وجه سفارش غذا جدا هستند. محتوای صفحهٔ اول از حساب رستوران نمونه مستقل است. پیام مدیر سیستم رسید خواندن هر گیرنده را جدا ذخیره می‌کند.

پرداخت زرین‌پال فقط sandbox است؛ مبلغ واقعی برداشت یا به کارت واریز نمی‌شود. قیمت طرح‌ها ۲۰۰ و ۵۰۰ هزار تومان است. قابلیت صوتی هوشمند و AR هنوز فعال نیستند.

مهاجرت‌ها به ترتیب در supabase/migrations قرار دارند. اجرای مهاجرت زنده، پشتیبان خصوصی رمزگذاری‌شده، بازیابی در محیط جدا و کنترل تطبیق داده می‌خواهد. migration_workspace_archive فقط آرشیو قفل‌شدهٔ اطلاعات قبلی است و هیچ مسیر runtime به آن دسترسی ندارد. فایل‌های مهاجرت تاریخی برای بازتولید و بازیابی حذف نمی‌شوند.

## کنترل و محدودیت‌ها

```text
pnpm lint
pnpm test:domains
pnpm test:notifications
pnpm test:billing
pnpm build
```

CI همین کنترل‌ها را قبل از انتشار main انجام می‌دهد. اعلان صدا نیاز به فعال‌سازی توسط کاربر دارد؛ Web Push در حالت بسته‌بودن برنامه پیاده نشده است. آفلاین اجازهٔ ثبت قطعی سفارش یا تغییر مالی نمی‌دهد. آزمون ورود واقعی پیامکی و اسکن/صدای دستگاه واقعی، مستقل از آزمون‌های محلی‌اند.

گزارش‌های دقیق انتقال و محدودیت‌ها: docs/architecture/.
