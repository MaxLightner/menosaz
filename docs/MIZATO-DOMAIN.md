# اتصال mizato.ir

در ۱۸ اکتبر ۲۰۲۶ دامنه در تلاش‌نت «در انتظار بررسی درخواست ثبت دامنه توسط ایرنیک» است. بخش مدیریت نیم‌سرورها صریحاً اعلام می‌کند دامنه فعال نیست و ویرایش ممکن نیست. DNS عمومی نیز NXDOMAIN برمی‌گرداند. فعال‌بودن سرویس در فهرست تلاش‌نت به معنی پایان ثبت در ایرنیک نیست.

تا رفع این وضعیت، دامنهٔ اصلی GitHub Pages و متغیر PUBLIC_SITE_URL تغییر نمی‌کند؛ تغییر زودهنگام باعث هدایت کاربران به دامنهٔ غیرقابل‌دسترسی خواهد شد.

## پس از تأیید ایرنیک

1. در پنل DNS فعال دامنه، رکوردهای زیر را تنظیم کنید. اگر تلاش‌نت فقط مدیریت نیم‌سرور می‌دهد، ابتدا سرویس DNS را مشخص کنید؛ نیم‌سرورها را به IP گیت‌هاب تغییر ندهید. رکورد ایمیل/MX یا TXT موجود حذف نشود.

| نام | نوع | مقدار |
|---|---|---|
| @ | A | 185.199.108.153 |
| @ | A | 185.199.109.153 |
| @ | A | 185.199.110.153 |
| @ | A | 185.199.111.153 |
| www | CNAME | maxlightner.github.io |

مقادیر از [مستند رسمی GitHub Pages](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) بررسی شده‌اند. CNAME نباید شامل نام مخزن یا مسیر /menosaz باشد. رکورد wildcard ساخته نشود.

2. مالکیت دامنه را در تنظیمات Pages حساب MaxLightner با TXT مخصوص همان حساب تأیید کنید. مقدار TXT باید از خود گیت‌هاب گرفته شود، نه حدس زده شود.
3. Settings → Pages مخزن menosaz: Custom domain برابر mizato.ir. پس از موفقیت DNS و صدور گواهی، Enforce HTTPS فعال شود.
4. در تنظیمات مخزن، Actions variable با نام PUBLIC_SITE_URL برابر https://mizato.ir قرار گیرد و workflow Pages دوباره اجرا شود. پایهٔ فایل‌های خروجی از همین URL استخراج می‌شود؛ آدرس فعلی /menosaz/ و دامنهٔ جدید با پایهٔ / پشتیبانی می‌شوند.
5. کد Edge آماده شده است: PUBLIC_SITE_URL مقدار مرجع callback پرداخت، qrCodeUrl خروجی و origin اصلی CORS است؛ فقط سه URL مشخص GitHub/mizato/www مجازند. روی Supabase، نسخهٔ آمادهٔ menu-api منتشر و PUBLIC_SITE_URL=https://mizato.ir و ALLOWED_ORIGINS شامل https://www.mizato.ir تنظیم شود. Site URL/Redirect URLهای Auth نیز بررسی شوند. کد Edge و تغییر Secrets مربوط به دامنه هنوز روی سرور اعمال نشده‌اند؛ فعلاً مرجع زنده همان GitHub است.
6. HTML، فایل‌های JS/CSS، تصاویر موجود در دیتابیس، ورود OTP و حفظ نشست، بازگشت پرداخت آزمایشی، QR تازه و هدایت QRهای چاپ‌شدهٔ قبلی روی HTTPS بررسی شوند. نشست مرورگر روی github.io خودکار به ir منتقل نمی‌شود؛ احتمال یک بار ورود دوباره وجود دارد.

این فایل گزارش آماده‌سازی است، نه تأیید فعال‌بودن دامنه. DNS، Custom domain، Secrets و callback تولید هنوز به میزاتو تغییر نکرده‌اند.
